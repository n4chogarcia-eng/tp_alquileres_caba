Carpeta para bases de datos complementarias.

serie_ipc_divisiones.csv
  IPC del INDEC por divisiones y regiones, tal como se descarga de
  https://www.indec.gob.ar/ftp/cuadros/economia/serie_ipc_divisiones.csv
  (base diciembre 2016 = 100, separado por punto y coma, coma decimal).

ipc_mensual.csv / ipc_trimestral.csv
  Generados por script/01 - crudo a preprocesado/00_ipc.R: nivel general,
  región GBA, base junio 2026 = 100, y su promedio trimestral. Se usan para
  deflactar los alquileres en la etapa 2.
